Safe Third-Party SVG Icons as True Inline SVGs

Unlike <img src="icon.svg"> which prevents CSS styling, or raw innerHTML which is vulnerable to XSS, <template for="icon" src="https://cdn.jsdelivr.net/..." sanitize> parses external vector files in a sanitized context. Embedded <script> tags and inline event handlers are stripped while preserving vector geometry and CSS stylability.

Buffered Atomic Commits vs. Progressive Stream Delivery

Smaller UI widgets (navigation, sidebars, comments) use the buffered attribute to parse into memory first and commit atomically on EOF, preventing layout shifts. Meanwhile, the main content feed streams chunk-by-chunk for instant perceived responsiveness.
