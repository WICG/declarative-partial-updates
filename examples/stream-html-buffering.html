Stream HTML with buffering

When streaming slow content, developers can buffer visual rendering to avoid flashes of partial content or layout shifts. The processing instructions are present from the start with a scoped style setting opacity: 0. When streaming completes, <template for="buffer"></template> clears the initial range and removes the <style> tag entirely, leaving zero footprint on the DOM.
